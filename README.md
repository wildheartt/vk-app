# VK App - Таблица пользовтелей

## Технологии

- React ^18.2.0
- TypeScript
- React Query для работы с API
- React Hook Form для управления формами
- JSON Server для мок API
- Jest и React Testing Library для тестирования

## Разработка

- `npm run dev` - запуск приложения и сервера одновременно
- `npm run test` - запуск тестов
- `npm run lint` - проверка кода линтером

## Структура проекта

- `/src/components` - React компоненты
- `/src/hooks` - кастомные хуки
- `/src/api` - функции для работы с API
- `/src/utils` - вспомогательные функции
- `/src/__tests__` - тесты
